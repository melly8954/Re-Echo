# Re-Echo FE

Re-Echo 프론트엔드 프로젝트입니다.

## Stack

- React
- Vite
- TypeScript
- TanStack React Query
- CSS Module

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Structure

```text
src
├─ pages
├─ features
├─ components
├─ shared
└─ stores
```

구조와 코딩 규칙은 상위 프로젝트의 `docs/coding-convention.md`를 따릅니다.
