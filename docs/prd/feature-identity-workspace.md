# Re-Echo 1차 MVP PRD: 인증과 워크스페이스


### 8.1 인증

- 소셜 로그인 지원
  - Google
  - Kakao
  - GitHub
- 최초 로그인 시 OAuth Provider의 이름과 프로필 이미지를 계정 기본
  프로필로 저장
- 계정 기본 프로필은 워크스페이스가 없는 상태와 새 멤버십의 초기값으로
  사용
- OAuth 로그인 실패 시 내부 원인을 노출하지 않고 로그인 화면으로
  이동하여 재시도를 안내
- 로그인 성공 시 access token은 응답 body로 반환
- 로그인/refresh 응답 헤더로 access token을 전달하지 않음
- refresh token은 HttpOnly cookie로만 전달
- refresh token cookie 정책
  - HttpOnly
  - Secure
  - SameSite=Lax
- refresh 시 access token을 반환
- refresh 시 refresh token도 재발급하여 기존 token을 교체
- 동일 사용자의 다중 브라우저·기기 로그인 세션을 허용
- refresh token은 세션별로 관리하며 logout 시 현재 세션만 무효화
- refresh 요청에서 refresh token 만료 또는 무효는 401과 `AUTH_*`
  비즈니스 예외로 처리
- logout은 멱등하게 처리하며 세션이 이미 종료되었거나 refresh token
  cookie가 없거나 만료·무효 상태여도 `200 OK`를 반환
- logout 요청 시 refresh token cookie는 항상 만료 처리
- logout 응답은 빈 `result`와 성공 메시지를 반환

### 8.2 워크스페이스

- 사용자당 여러 워크스페이스 생성 가능
- 워크스페이스 목록은 사용자의 생성·참여 등록 순서로 노출하며,
  마지막 방문 이후에도 위치를 변경하지 않음
- 로그인 후 최근 방문한 활성 워크스페이스의 홈으로 진입
- 활성 워크스페이스가 없을 때만 워크스페이스 생성과 초대 링크 참여를
  제공하는 빈 상태를 표시
- 워크스페이스 전환은 왼쪽 워크스페이스 레일에서 제공
- 워크스페이스 생성과 초대 링크 참여는 레일 하단 `+` 메뉴에서 제공
- 현재 워크스페이스의 홈과 채널 목록은 워크스페이스 레일과 분리된
  채널 사이드바에서 제공
- 워크스페이스 진입 시 마지막 방문 시각을 갱신
- 워크스페이스 역할 구조
  - 소유자
  - 관리자
  - 일반 멤버
- 워크스페이스에는 항상 1명의 소유자가 있어야 함
- 마지막 소유자는 스스로 관리자 또는 일반 멤버로 변경할 수 없음
- 관리자 임명/해제는 소유자만 가능
- 워크스페이스 이름 변경은 소유자만 가능
- 관리자는 워크스페이스 설명과 대표 이미지만 변경 가능
- 워크스페이스는 소유자만 보관 가능
- 관리자는 워크스페이스를 보관하거나 복원할 수 없음
- 활성 워크스페이스 재진입 시 워크스페이스 홈으로 진입하고, 채널은
  홈 또는 채널 목록에서 선택
- 워크스페이스 홈에는 전체 참여자 수와 채널별 인원 수를 표시
- 보관된 워크스페이스는 15일 내 복원 가능
- 보관된 워크스페이스 상세에는 복원 가능 여부 `canRestore`를 포함
- 보관된 워크스페이스는 멤버가 홈에서 보관 상태를 확인할 수 있음
- 보관된 워크스페이스에서는 채널 목록과 기존 채널을 노출하지 않음
- 15일 경과 후 자동 삭제

### 8.3 초대

- 소유자/관리자만 초대 링크 발급 가능
- 초대 링크 만료 시간은 24시간
- 워크스페이스에는 하나의 활성 초대 링크만 유지
- 활성 초대 링크가 있으면 링크 복사/조회 시 기존 링크를 재사용
- 명시적으로 초대 링크를 재발급할 때만 기존 링크 자동 무효화
- 초대 링크 조회·발급·복사는 워크스페이스 홈에서만 제공
- 비로그인 사용자도 초대 링크에서 워크스페이스 이름, 대표 이미지 등
  최소 정보는 확인 가능
- 자진 탈퇴한 멤버는 초대 링크로 재참여 가능
- 강제 제거된 멤버는 재초대 불가

### 8.4 멤버 관리

- 일반 멤버와 관리자는 자진 탈퇴 가능
- 소유자는 MVP에서 자진 탈퇴 불가, 워크스페이스 보관으로 대체
- 관리자 강제 제거 가능
- 일반 멤버도 워크스페이스 전체 멤버 목록 조회 가능
- 멤버 목록에는 워크스페이스별 닉네임, 프로필 이미지, 역할을 표시
- 멤버 목록에는 이메일을 노출하지 않음
