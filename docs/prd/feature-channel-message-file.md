# Re-Echo 1차 MVP PRD: 채널, 메시지, 파일

### 8.5 채널

- `#general` 기본 생성
- 워크스페이스 합류 시 `#general`만 자동 참여
- `#general`은 필수 참여 채널이며 나갈 수 없음
- 활성 워크스페이스의 `#general`은 이름·설명 수정과 개별 보관을 허용하지 않음
- 워크스페이스 보관·복원 시에만 `#general`을 하위 채널과 함께 상태 전환
- 공개 채널 지원
- 비공개 채널 지원
- 채널 생성은 소유자/관리자 가능
- 채널 목록은 `#general` 우선, 나머지는 최근 활동 순으로 노출
- 채널 화면에는 채널 참여·나가기처럼 채널 범위 동작만 제공하며,
  워크스페이스 나가기는 홈에서만 제공
- 공개 채널은 참여/나가기/재참여 지원
- 공개 채널은 워크스페이스 멤버에게 채널 존재가 공개됨
- 공개 채널은 워크스페이스 멤버라면 언제든 자유롭게 참여 가능
- 공개 채널은 참여 전 메시지 미리보기는 제공하지 않음
- 공개 채널 참여 후에는 과거 메시지 전체 조회 가능
- 비공개 채널 멤버 관리는 모든 관리자 가능
- 비공개 채널 생성 시 생성자는 자동 포함되며 초기 멤버를 추가로 선택
  할 수 있음
- 비공개 채널도 자진 나가기를 지원함
- 비공개 채널에서 자진 나간 멤버는 관리자 추가를 통해 재참여 가능
- 공개/비공개 채널 모두 강제 제거된 멤버는 재참여할 수 없음
- 비공개 채널 생성자는 채널 보관 전까지 자진 나가기와 강제 제거를
  허용하지 않음
- 비공개 채널은 비멤버에게 목록과 존재를 노출하지 않음
- 비공개 채널의 멤버 목록은 비멤버에게 공개하지 않음
- 비공개 채널에 새로 추가된 멤버도 과거 메시지 전체 조회 가능
- `#general`을 제외한 채널은 즉시 삭제하지 않고 보관만 지원
- 보관된 채널은 15일 내 복원 가능
- 보관된 채널은 읽기 전용으로 유지
- 보관된 채널의 삭제 예정일은 일반 멤버에게도 노출
- 15일 경과 후 자동 삭제

### 8.6 메시지

- 실시간 텍스트 메시지 송수신
- 최신 메시지 기준 진입
- 과거 메시지는 위로 스크롤하며 로드
- 메시지 목록은 cursor pagination을 사용
- 메시지 cursor 기준값은 `createdAt + messageId` 조합
- 메시지 전송 성공/실패 상태 표시
- 실패 시 재전송 지원
- 입력 중 표시 지원
- 텍스트 없이 첨부만 있는 메시지도 허용
- 본인 메시지만 수정 가능
- 메시지 수정 가능 시간은 제한하지 않음
- 관리자는 모든 멤버의 메시지 삭제 가능
- 소유자의 메시지도 관리자 삭제 가능
- 관리 권한자가 타인 메시지를 삭제할 때는 강제 삭제임을 명확히 안내
- 메시지 삭제 시 타임라인에는 삭제된 메시지 흔적을 남기며, 관리 권한자가
  삭제한 경우 관리 권한에 의한 삭제임을 표시
- 보관된 채널에서는 메시지 작성, 수정, 삭제를 허용하지 않음
- 읽음 갱신은 REST API로만 처리
- 읽음 상태에 대한 별도 broadcast는 제공하지 않음

### 8.7 파일

- 파일 첨부 지원
- 파일 종류는 대체로 허용
- 메시지 첨부 파일 1개당 최대 20MB
- 프로필 이미지는 이미지 파일만 허용하며 1개당 최대 10MB
- 워크스페이스 대표 이미지는 이미지 파일만 허용하며 1개당 최대 10MB
- 워크스페이스 `OWNER`, `ADMIN`은 대표 이미지를 업로드, 교체, 제거할 수 있음
- 이미지 파일만 기본 미리보기 지원
- 파일 저장소는 외부 오브젝트 스토리지 사용
  - 우선 후보: Cloudflare R2
- Presigned URL 방식으로 직접 업로드/다운로드
- Presigned URL 발급 API는 파일 1개씩만 처리
- Presigned URL 발급 요청값은 `fileName`, `contentType`, `size`를 사용
- 업로드만 완료된 파일은 임시 파일 상태로 관리
- 메시지 생성/수정 시 `fileId`가 연결되어야 최종 첨부로 확정
- 프로필과 워크스페이스 대표 이미지는 수정 시 `fileId`가 연결되어야
  최종 이미지로 확정
- 파일 메타데이터는 애플리케이션 DB에서 관리
