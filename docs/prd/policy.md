# Re-Echo 1차 MVP PRD: 권한, UX, 운영 정책

## 9. 권한 정책 요약

- 소유자:
  - 관리자 권한 포함
  - 관리자 임명/해제
  - 워크스페이스 이름 변경
  - 워크스페이스 보관
- 관리자:
  - 채널 생성
  - 초대 링크 발급
  - 워크스페이스 설명·대표 이미지 변경
  - 멤버 강제 제거
  - 비공개 채널 멤버 관리
  - 메시지 삭제
- 일반 멤버:
  - 메시지 작성
  - 본인 메시지 수정
  - 자진 탈퇴

## 10. UX 원칙

- 카카오톡/디스코드처럼 최신 메시지 기준으로 진입한다.
- 채널 협업에 필요한 흐름을 빠르게 완료할 수 있어야 한다.
- 푸시 알림보다 채널 목록 중심의 안읽음 확인에 집중한다.
- 채팅 UX는 직관적으로, 권한 정책은 단순하게 유지한다.
- 활성 워크스페이스에서는 홈에서 전체 현황을 확인한 뒤 채널로 이동한다.
- 보관된 워크스페이스는 홈에서 보관 상태와 복원 가능 여부만 확인할 수
  있어야 하며, 채널은 복원 후 다시 노출한다.

## 11. 데이터/운영 정책

- 워크스페이스와 채널은 보관 후 15일이 지나면 자동 삭제한다.
- 복원은 보관 기간 내에서만 허용한다.
- 워크스페이스 보관 시 내부 채널도 함께 보관 처리한다.
- 파일은 애플리케이션 서버가 아닌 외부 스토리지에 저장한다.
- 메시지 첨부 또는 프로필 이미지로 최종 연결되지 않은 orphan 파일은
  하루 단위 배치로 정리한다.
- 자진 탈퇴한 멤버는 다시 참여할 수 있다.
- 강제 제거된 멤버는 재초대할 수 없다.

## 12. 완료 기준

- 아래 흐름이 끊김 없이 데모 가능해야 한다.
  1. 소셜 로그인
  2. 워크스페이스 생성
  3. 초대 링크 발급
  4. 멤버 합류
  5. `#general` 진입
  6. 공개/비공개 채널 생성
  7. 실시간 메시지 송수신
  8. 파일 첨부 및 이미지 미리보기
  9. 채널 안읽음 배지 확인
