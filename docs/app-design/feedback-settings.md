# Re-Echo App Design: 피드백과 설정

### 5.12 Error and Empty State

오류와 빈 상태는 원인 설명과 다음 행동을 함께 제공한다.

일시적인 오류는 짧은 문구와 재시도 버튼으로 단순하게 표시한다.

빈 상태나 온보딩 성격의 화면에는 가벼운 아이콘을 사용할 수 있다.

권한 오류, 만료, 유효하지 않은 초대처럼 사용자가 조치해야 하는 상태는
원인을 명확히 설명하고 다음 행동 버튼을 제공한다.

큰 일러스트나 과한 장식은 사용하지 않는다.

### 5.13 Loading and Skeleton

로딩 상태는 영역별 skeleton을 기본으로 한다.

채널 목록, 메시지 목록, 워크스페이스 카드처럼 반복 구조가 있는 영역은
실제 레이아웃과 유사한 skeleton을 표시한다.

짧은 로딩은 불필요한 깜빡임을 줄이기 위해 즉시 표시하지 않을 수 있다.

버튼 클릭 후 처리 중 상태는 버튼 내부 spinner 또는 disabled 상태로
표시한다.

전체 화면 spinner는 초기 앱 부팅이나 인증 확인처럼 화면 전체가 준비되지
않은 경우에만 사용한다.

### 5.14 Toast and Inline Feedback

짧고 전역적인 피드백은 오른쪽 아래 toast로 표시한다.

복사 완료, 저장 완료, 초대 링크 복사 완료처럼 사용자가 추가 조치를
하지 않아도 되는 상태는 toast를 사용한다.

입력값 오류, 초대 링크 오류, 메시지 전송 실패처럼 사용자가 바로
조치해야 하는 상태는 해당 입력 영역, 메시지 행, composer 근처에
inline feedback으로 표시한다.

toast는 자동으로 사라질 수 있지만, 오류 toast는 사용자가 읽을 수
있도록 충분한 시간을 제공한다.

같은 메시지의 toast를 짧은 시간에 중복해서 쌓지 않는다.

### 5.15 Modal and Confirmation

확인 모달은 되돌리기 어렵거나 영향 범위가 큰 작업에만 사용한다.

삭제, 워크스페이스 나가기, 채널 나가기, 초대 링크 재생성, 권한 변경처럼
사용자 또는 다른 구성원에게 영향을 주는 작업은 확인 모달을 사용한다.

일반 저장, 복사, 전송, 입력 오류 같은 작업은 확인 모달 대신 toast 또는
inline feedback으로 처리한다.

확인 모달은 남용하지 않으며, 사용자의 흐름을 끊을 필요가 있는 작업에만
제한한다.

### 5.16 Permission and Disabled State

권한과 비활성 UI는 주요 액션과 숨겨도 되는 기능을 구분해서 처리한다.

사용자가 현재 맥락에서 볼 필요가 있는 주요 액션은 disabled 상태로
표시하고, tooltip 또는 inline text로 이유를 제공한다.

권한이 없어 접근할 수 없는 관리 메뉴, MVP 범위에 없는 기능, 사용자에게
의미 없는 액션은 표시하지 않는다.

disabled 버튼은 hover/focus 시에도 이유를 확인할 수 있어야 한다.

모바일에서는 tooltip 대신 보조 문구나 toast를 사용할 수 있다.

### 5.17 Top Bar Menu

상단바는 브랜드와 사용자 메뉴를 제공한다.

워크스페이스 목록은 별도 왼쪽 레일에 배치하고, 생성·초대 참여는 레일 하단
`+` 메뉴로 제공한다. 채널 사이드바에는 현재 워크스페이스 홈 진입점과
채널 목록만 둔다.

상단 오른쪽에는 사용자 프로필 메뉴를 배치한다.

상단 `프로필` 진입점은 단일 프로필 설정 화면으로 이동한다. 이 화면은
전체 프로필과 현재 워크스페이스 프로필을 선택할 수 있어야 한다. 전체
프로필은 모든 워크스페이스의 기본 표시 이름과 이미지를 수정하며, 현재
워크스페이스 프로필은 그 워크스페이스에만 표시되는 닉네임과 이미지를
수정한다. 워크스페이스 프로필을 선택한 경우에는 `이 워크스페이스` 같은
지시어 대신 실제 워크스페이스 이름을 제목과 안내 문구에 표시한다.
워크스페이스 프로필 영역에는 참여 중인 활성 워크스페이스를 전환할 수 있는
선택기를 제공하며, 상단 `프로필` 진입점으로 전달된 워크스페이스를 기본
선택값으로 사용한다.

워크스페이스 맥락의 설정과 사용자 계정 설정은 메뉴 안에서 명확히
구분한다.

모바일에서는 워크스페이스 레일과 생성·초대 참여 메뉴, 현재 워크스페이스 홈
탐색을 채널 drawer 내부에 제공하고, 상단에는 drawer 열기와 사용자 메뉴를
유지한다.

### 5.18 Theme

MVP에서는 라이트 모드만 지원한다.

다크 모드는 후속 확장 대상으로 둔다.

색상은 향후 다크 모드 확장이 가능하도록 CSS 변수 기반 token으로
관리한다.
