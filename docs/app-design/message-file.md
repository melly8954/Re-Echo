# Re-Echo App Design: 메시지와 파일

### 5.7 Message List

메시지 목록은 행 기반 레이아웃을 기본으로 한다.

같은 작성자의 연속 메시지는 하나의 메시지 그룹으로 묶고, 첫 메시지에만
작성자명과 아바타를 표시한다. 작성자명은 말풍선 밖, 아바타 오른쪽 위에
배치하고 말풍선에는 메시지 본문만 표시한다.

같은 작성자라도 날짜가 바뀌거나 5분 이상 간격이 있으면 새 메시지
그룹으로 분리한다.

각 메시지 행에는 hover 시 상세 시간, 전송 상태를 표시할 수 있다.
전송 시각은 말풍선 바깥 하단에 둔다.

내가 보낸 메시지와 다른 참여자의 메시지는 모두 연한 배경과 테두리를
가진 말풍선으로 표시한다. 내 메시지는 강조 색으로 구분한다.

내가 보낸 메시지는 행을 오른쪽에 정렬하고, 다른 참여자가 보낸 메시지는
왼쪽에 정렬한다. 다른 참여자 메시지에는 그룹의 첫 메시지에만 작성자명과
아바타를 표시한다. 내 메시지는 우측 정렬과 강조 색으로만 구분하며 별도
발신자명을 표시하지 않는다.

수정과 삭제는 메시지 행의 작업 메뉴에서 제공한다. 권한이 있는 메시지의
말풍선 오른쪽 상단에는 클릭 가능한 `⋯` 버튼을 기본 진입점으로 둔다.
데스크톱에서는 마우스 우클릭, 모바일에서는 길게 누르기, 키보드에서는
컨텍스트 메뉴 키 또는 `Shift+F10`으로도 메뉴를 열 수 있다. 선택 시 해당
메시지 근처의 작은 팝업으로 동작을 제시한다. 본인 메시지의 삭제 항목은
`삭제`로 표시한다. `OWNER`, `ADMIN`이 타인 메시지에 대해 수행하는 삭제는
`강제 삭제`로 표시하고, 확인 모달에도 대상 작성자와 관리 권한에 의한 삭제임을
명시한다. 삭제는 기존 확인 모달을 거친다. 삭제된 메시지는 기본 삭제 흔적을
남기며, 관리 권한자가 삭제한 타인 메시지는 `관리 권한에 의해 삭제된 메시지입니다.`로
구분해 표시한다.

메시지 목록만 독립적으로 세로 스크롤한다. 채널 헤더와 composer는
메시지 목록의 스크롤에 따라 함께 움직이지 않으며, 긴 대화에서도
composer는 화면 하단에 유지한다.

채널에 처음 진입하거나 다른 채널로 전환하면 메시지 목록은 최신 메시지가
하단에 보이는 위치로 이동한다. 사용자가 과거 메시지를 읽기 위해 위로
스크롤한 상태라도 새 메시지가 생기면 발신자와 관계없이 최신 메시지가
보이는 하단으로 이동한다.

채널 대화의 가독성을 위해 말풍선의 배경색과 테두리는 낮은 대비로
유지한다.

### 5.8 Message Composer

메시지 입력창은 여러 줄 입력이 가능한 composer 형태로 제공한다.

기본 높이는 한 줄 입력에 맞추되, 입력 내용이 길어지면 일정 높이까지
확장된다.

메시지 전송에 성공하면 입력 내용을 비우고 composer 입력창에 다시
포커스를 둔다. 연속 메시지를 작성할 때 사용자가 입력창을 다시 선택할
필요가 없어야 한다.

- composer는 첨부 트레이, 입력 영역, `+`, 전송 버튼을 하나의 둥근
  표면으로 묶어 메신저처럼 보이게 한다.
- 채널명 안내 라벨은 시각적으로 반복하지 않고 입력창의 접근 가능한
  이름과 placeholder로 제공한다.
- 파일 첨부는 입력창 왼쪽의 원형 `+` 버튼으로 진입한다.
- `+` 버튼을 누르면 입력창을 가리지 않는 작은 첨부 메뉴를 열고,
  현재 MVP에서는 `파일 선택` 항목을 제공한다.
- 첨부 메뉴는 항목 선택, 메뉴 바깥 클릭 또는 `Esc` 입력 시 닫는다.
- 전송 버튼은 입력창 오른쪽의 원형 아이콘 버튼으로 배치한다.
- `Enter`는 전송, `Shift+Enter`는 줄바꿈을 기본 동작으로 한다.

### 5.9 File Attachment

파일을 선택하면 메시지 입력창 위에 첨부 미리보기 영역을 표시한다.

- 첨부 미리보기는 composer 높이를 과도하게 늘리지 않는 가로 스크롤
  트레이로 제공한다.
- 이미지 파일은 64px 정사각 썸네일로 보여주고, 제거 버튼은 썸네일
  오른쪽 위에 겹쳐 표시한다.
- 일반 파일은 파일명과 용량만 포함한 작은 칩으로 표시한다.
- 업로드 중·실패 상태만 각 항목에 표시하고, 완료 상태는 별도 문구로
  반복하지 않는다.
- 제거 버튼은 마우스·터치에서 즉시 인지할 수 있는 `×` 아이콘으로
  제공하되 접근 가능한 이름을 함께 제공한다.
- 전송된 이미지 첨부는 채팅 타임라인에서 가로 최대 260px의 큰
  미리보기로 표시하고, 누르면 원본을 연다.
- 전송된 일반 파일은 아이콘, 파일명, 용량만 포함한 압축된 파일 카드로
  표시한다.
- 첨부만 전송한 메시지는 빈 텍스트 본문을 만들지 않되, 이미지·파일은
  다른 메시지와 구분되는 첨부 말풍선 안에 표시한다.
- 업로드가 완료된 첨부가 하나 이상 있으면 메시지 본문이 비어 있어도
  전송 버튼을 활성화한다.
- 사용자는 파일을 composer 영역에 드래그앤드롭해도 기존 파일 선택과
  동일한 첨부·업로드 흐름을 시작할 수 있다.

### 5.10 Typing Indicator

입력 중 표시는 메시지 목록 하단, composer 바로 위에 표시한다.

“OOO님이 입력 중...” 문구와 작은 점 애니메이션을 함께 사용한다.

여러 명이 입력 중이면 최대 2명까지 이름을 표시하고, 그 이상은 “외
N명” 형태로 축약한다.

입력 중 표시가 없을 때도 composer 위치가 크게 흔들리지 않도록 영역
높이를 안정적으로 관리한다.

채널 헤더에는 입력 중 상태를 표시하지 않는다.

### 5.11 Invite Link

초대 링크 화면은 참여 전에 사용자가 어떤 워크스페이스에 들어가는지
확인할 수 있게 구성한다.

워크스페이스 이름, 초대한 사람, 초대 링크 만료 여부를 표시한다.

유효한 초대라면 “참여하기” 버튼을 제공한다. 만료되었거나 유효하지
않은 초대라면 참여 버튼을 비활성화하고 사유를 명확히 안내한다.

로그인이 필요한 경우에는 로그인 후 같은 초대 흐름으로 돌아올 수
있어야 한다.
