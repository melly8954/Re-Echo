# Re-Echo App Design: 반응형 기준


### 4.1 Breakpoint

Re-Echo는 다음 화면 크기 기준을 사용한다.

```text
Mobile: < 768px
Tablet: 768px ~ 1023px
Laptop: 1024px ~ 1439px
Desktop: >= 1440px
```

구간을 세분화하되, 모든 구간에서 완전히 다른 UI를 만들지는 않는다.
레이아웃 전환 기준을 명확히 하기 위한 구분으로 사용한다.

### 4.2 Mobile

모바일에서는 메시지 화면을 기본 화면으로 사용한다.

워크스페이스 선택, 홈, 채널 목록은 상단의 메뉴 버튼을 통해 drawer로
연다. drawer 상단에는 가로 스크롤 워크스페이스 레일과 `+` 메뉴를 두고,
그 아래에 현재 워크스페이스 이름을 홈 진입점으로 표시한 뒤 채널 목록을
제공한다. drawer가 열리면 배경 스크롤을 막고, `Esc` 또는 닫기 버튼으로
닫을 수 있어야 한다.

채널을 선택하면 drawer를 닫고 해당 메시지 화면으로 이동한다.

### 4.3 Tablet

Tablet 구간에서는 화면 방향에 따라 레이아웃을 다르게 적용한다.

- 세로 방향에서는 모바일과 동일하게 메시지 화면을 기본으로 하고,
  채널 목록은 drawer로 제공한다.
- 가로 방향에서는 데스크톱과 동일하게 채널 사이드바와 메시지 본문을
  함께 노출한다.

### 4.4 Laptop and Desktop

Laptop과 Desktop에서는 왼쪽 채널 사이드바와 오른쪽 메시지 본문을
기본 구조로 사용한다.

Desktop에서는 Laptop 구조를 유지하되, 여백, 사이드바 폭, 메시지
본문 최대 너비를 안정적으로 조정한다.
