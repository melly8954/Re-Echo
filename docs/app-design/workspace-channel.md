# Re-Echo App Design: 로그인, 워크스페이스, 채널

## 5. 화면별 UI 규칙

이 섹션은 화면별 UI 구현 기준을 정의한다.

### 5.1 Login

로그인 화면은 별도 랜딩형 페이지보다 앱 레이아웃 안에서 로그인을
유도하는 방식으로 구성한다.

비로그인 상태에서는 채널/메시지 앱 레이아웃을 흐릿한 빈 상태로
보여주고, 중앙에 로그인 패널을 표시한다.

- 배경 앱 레이아웃에는 실제 채널명, 메시지, 사용자 정보를 노출하지
  않는다.
- 배경에는 skeleton, placeholder, 비식별 텍스트만 사용한다.
- 로그인 패널에는 Re-Echo의 짧은 설명과 소셜 로그인 버튼을 배치한다.
- 설명은 제품 소개보다 로그인 후 사용할 협업 채팅 경험을 짧게
  안내하는 수준으로 제한한다.

### 5.2 First Entry After Login

로그인 후 사용자는 최근 방문 시각이 가장 최신인 활성 워크스페이스의 홈으로
바로 진입한다. 보관된 워크스페이스는 자동 진입 대상에서 제외한다.

접근 가능한 활성 워크스페이스가 없거나 접근 권한이 사라진 경우에는
워크스페이스 생성과 초대 링크 참여를 위한 빈 상태를 노출한다.

초대 링크로 진입한 경우에는 초대된 워크스페이스 참여 흐름을 우선한다.

### 5.3 Workspace Empty State

활성 워크스페이스가 있는 사용자에게는 별도의 Re-Echo 전체 홈을 제공하지
않는다. 상단의 Re-Echo 브랜드는 현재 화면을 벗어나게 하는 링크가 아니라
정적 브랜드로 표시한다.

사용자가 접근 가능한 활성 워크스페이스가 없을 때는 생성과 참여를 같은
우선순위의 빈 상태로 제공한다.

“새 워크스페이스 만들기”와 “초대 링크로 참여”는 나란한 카드 또는
동일한 시각적 비중의 선택지로 표시한다.

- 생성 카드는 워크스페이스 이름, 설명, 선택형 대표 이미지 입력 흐름으로
  연결한다. 대표 이미지는 JPG, PNG, WebP 10MB 이하만 선택할 수 있으며,
  생성 직후 워크스페이스에 연결한다.
- 참여 카드는 초대 링크 입력 또는 초대 링크 검증 흐름으로 연결한다.

### 5.4 Workspace Home

워크스페이스 홈은 채널 대화와 분리된 워크스페이스 단위의 요약 화면이다.

- 워크스페이스 이름, 설명, 내 역할, 전체 참여자 수와 채널 수를 표시한다.
- `OWNER`, `ADMIN`에게는 전체 참여자 요약 카드 우측 상단에 멤버 관리
  버튼을 제공한다.
- 우측 보조 패널에는 워크스페이스 전체 참여자를 `OWNER`, `ADMIN`,
  `MEMBER` 역할별로 나누어 표시한다. 각 항목에는 워크스페이스별
  닉네임과 프로필 이미지를 표시하며, 멤버 관리 동작은 제공하지 않는다.
- 우측 보조 패널의 내 참여자 항목은 우클릭 또는 키보드 실행 시
  `워크스페이스 프로필 편집` 메뉴를 표시한다. 메뉴 선택 시 프로필 설정
  화면의 현재 워크스페이스 프로필 영역으로 이동한다.
- 각 채널은 공개 범위, 채널 참여자 수, 읽지 않은 메시지 수를 카드로
  표시하고 선택 시 해당 채널 대화로 이동한다.
- `OWNER`, `ADMIN`에게만 활성 초대 링크 전체와 복사 버튼을 표시한다.
  활성 링크가 없으면 발급 버튼을 제공한다.
- 초대 링크 만료 시각은 이 화면의 기본 표시 정보에 포함하지 않는다.
- 워크스페이스 나가기는 홈에서만 제공하고, 확인 모달을 거친다.
  소유자에게는 나가기 버튼을 표시하지 않는다.
- 홈 헤더에는 별도의 `내 프로필` 버튼을 두지 않는다. 현재
  워크스페이스 프로필 수정은 우측 참여자 목록의 내 항목과 상단
  `프로필` 설정 진입점에서 제공한다.
- 채널 사이드바 상단에는 현재 워크스페이스 이름을 홈 진입점으로 두고,
  채널 목록을 그 아래에 둔다. 워크스페이스 전환과 생성·초대 참여는
  별도 워크스페이스 레일에서 처리한다.
- `OWNER`, `ADMIN`에게는 채널 목록 제목 옆에 채널 생성 버튼을 표시한다.
- `OWNER`, `ADMIN`에게는 헤더에 워크스페이스 설정 버튼을 제공한다.
  설정 화면에서는 대표 이미지와 설명을 수정할 수 있고, 이름은 `OWNER`만
  수정할 수 있다. `ADMIN`에게는 현재 이름을 읽기 전용으로 표시한다.
  대표 이미지는 현재 이미지 또는 이름 첫 글자 대체 표시, `이미지 선택`,
  `이미지 제거`를 제공하며 JPG, PNG, WebP 10MB 이하 제약을 선택 즉시 안내한다.
- `OWNER`에게는 워크스페이스 설정 하단에 보관 영역을 제공한다. 보관은
  모든 활성 채널을 읽기 전용으로 전환하며 15일 내에만 복원할 수 있다는
  설명과 별도 확인 모달을 거친다. 보관 성공 후에도 현재 워크스페이스
  홈에 머물며 전용 보관 상태 화면으로 전환한다.
- 워크스페이스 헤더에는 이름과 설명만 표시하고 역할·상태 badge는
  표시하지 않는다. 복원은 `canRestore`가 참인 `OWNER`에게 전용 보관
  상태 패널에서만 제공하며, `ADMIN`과 `MEMBER`에게는 보관·복원 동작을
  노출하지 않는다.
- 보관된 워크스페이스 홈에서는 채널 수, 채널 현황, 채널 빈 상태를
  표시하지 않는다. 중앙에는 채널이 복원 전까지 숨겨진다는 안내와
  소유자만 복원할 수 있다는 전용 보관 상태 패널을 표시한다. 채널
  사이드바도 일반 빈 상태 대신 복원 후 다시 표시된다는 안내를 사용한다.

### 5.5 Channel List

채널 목록은 단순한 사이드바 목록을 기본으로 한다.

공개 채널과 비공개 채널은 아이콘으로 구분한다. 채널 수가 적을 때는
하나의 목록처럼 보이게 유지하고, 채널 수가 늘어날 경우 공개/비공개
라벨을 사용해 탐색성을 높인다.

채널 생성 화면에서는 채널 이름, 선택형 설명, 공개 범위를 입력한다.
설명은 비워 둘 수 있으며, 비공개 채널일 때만 초기 멤버를 함께 선택한다.

각 채널 행의 끝에는 권한이 있는 동작만 아이콘 버튼으로 둔다.
`OWNER`, `ADMIN`은 `#general`을 제외한 채널에서 단순 톱니바퀴 아이콘으로
설정 화면을 열 수 있고, 참여 중인 사용자는 나갈 수 있는 채널에서 문과
화살표 아이콘으로 나가기 확인 모달을 연다. 아이콘 버튼은 채널 이동 링크와
분리하고 hover 또는 focus 상태에서 표시한다.

즐겨찾기나 최근 채널 그룹은 MVP 기본 규칙에 포함하지 않는다.

### 5.6 Channel State

채널 목록에서는 선택된 채널, 읽지 않은 채널, 읽지 않은 개수를 함께
표현한다.

선택된 채널은 연한 청록 배경, 왼쪽 accent bar 또는 아이콘 강조,
명확한 텍스트 색상과 weight로 표현한다.

읽지 않은 채널은 채널명을 굵게 표시하고 왼쪽 작은 점을 사용할 수
있다. 읽지 않은 개수는 오른쪽 숫자 배지로 표시하며, `99`개 초과는
`99+`로 표시한다.

선택 상태와 읽지 않은 상태가 겹치면 선택 배경을 우선하고, 읽지 않은
숫자 배지는 유지한다. 왼쪽 점이 선택 accent bar와 겹치면 생략할 수
있다.

멘션 전용 강조 규칙은 MVP 범위에 포함하지 않는다.

보관된 채널은 목록에 유지하되 보관 상태와 자동 삭제 예정일을 함께
표시한다. 보관된 채널 대화에서는 기존 메시지를 읽을 수 있지만 composer와
메시지 수정·삭제 동작은 제공하지 않는다. `OWNER`, `ADMIN`은 `#general`을
제외한 채널 행의 설정 아이콘에서 이름·설명을 수정하고, 보관 또는 복원을
수행한다. 보관은 영향 범위와 15일 복원 가능 기간을 안내한 뒤 확인 모달을
거친다. `#general`은 워크스페이스 보관·복원 시에만 함께 상태가 전환된다.
채널 헤더에는 채널 이름과 설명만 표시하며 역할·워크스페이스 운영 상태·채널
보관 상태 badge와 관리 버튼은 표시하지 않는다.
